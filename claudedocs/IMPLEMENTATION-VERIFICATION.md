### Impact Level Logic

Specification:
```
- CRITICAL: root_config changed
- HIGH: >3 servers
- MEDIUM: 2-3 servers
- LOW: 1 server
```

Implementation:
```bash
if [ "$root_config_changed" = "true" ]; then
  impact_level="CRITICAL"
elif [ "$affected_count" -gt 3 ]; then
  impact_level="HIGH"
elif [ "$affected_count" -ge 2 ]; then
  impact_level="MEDIUM"
elif [ "$affected_count" -eq 1 ]; then
  impact_level="LOW"
else
  impact_level="NONE"
fi
```

## Known Limitations & Notes

1. **Server Discovery**: The all_servers list is dynamically generated from filesystem
   - Will automatically include new servers
   - May include non-MCP directories if placed in mcp_servers/
   - Recommendation: Verify output for unexpected entries

2. **Path Filter Regex**: Uses glob patterns, not full regex
   - Sufficient for current monorepo structure
   - If complex patterns needed, can extend filters

3. **Output Size**: JSON arrays in workflow outputs have size limits
   - Current: 13 servers (minimal risk)
   - Future: If >50 servers, may hit GitHub limits
   - Mitigation: Use pagination or compression

4. **Timeout**: 5 minutes is conservative estimate
   - Typical execution: <1 minute
   - Scales with repository size
   - Can be adjusted if needed
